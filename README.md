
# MAX AI - ChatBot using LangChain<br>

This is a simple console-based AI Chatbot developed using Python, LangChain, and Google's Gemini-2.5-Flash model. It maintains chat history during the session to provide contextual answers.<br>

## Features
- **Context-aware conversations:** Remembers previous chats during the session.
- **Powered by Google Gemini:** Uses the fast and efficient `gemini-2.5-flash` model.
- **Interactive UI:** Simple and clean console-based user interface.<br>
